Step 1 — User enters details (Login.tsx)
On /login, the user enters:

First name (required)
Last name (optional)
10-digit Indian mobile number
Clicking Send OTP calls POST /api/auth/otp/send.

Step 2 — Send OTP API (app/api/auth/otp/send/route.ts)
Validates first name and mobile (6–9 + 9 digits).
If OTP_SMS_ENABLED=true, checks Nimbus credentials exist.
Generates a 6-digit OTP (random when SMS is on; fixed 123456 in demo mode).
Sets expiry to 10 minutes (OTP_VALID_MINUTES = 10).
Upserts the user in Supabase:
Existing mobile → updates name + OTP
New mobile → creates user row
If SMS enabled → calls Nimbus via sendNimbusOtpSms().
Returns { smsSent, otpValidMinutes, user } (and demoOtp only when SMS is off).


Step 3 — Nimbus SMS (lib/server/nimbus-sms.ts)
Builds the same URL as your PHP example:

https://nimbusit.biz/api/SmsApi/SendSingleApi
  ?UserID=hexabiz
  &Password=...
  &SenderID=HEXACR
  &Phno=9693946929
  &Msg=Your+Hexa+Cards+mobile+number+verification+OTP+is+121233...
  &EntityID=1701178799996228439
  &TemplateID=1777178824647145094
Uses HTTPS (your sample URL used HTTPS too).
Password stays in env — not hardcoded in source.
Parses JSON response; succeeds when Status === "OK".
On failure → API returns 502 with an error message.


Step 4 — User enters OTP (Login.tsx)
Shows: "OTP sent via SMS to +91 … Valid for 10 minutes."
60-second resend cooldown.
In demo mode, auto-fills 123456 and shows a hint.


Step 5 — Verify OTP API (app/api/auth/otp/verify/route.ts)
Loads user by mobile from Supabase.
Compares entered OTP with stored users.otp.
Rejects if expired (otp_expiry passed).
Clears OTP from DB (otp = null, otp_expiry = null).
Sets is_mobile = 1 (verified).
Creates a user_session row (session ID + token).
Returns user + session to the client.


Step 6 — Login complete (Login.tsx)
Saves session via setAuthUser().
Redirects to dashboard or checkout (?next= param).
Enable real SMS (production)
Add to frontend/.env.local:

OTP_SMS_ENABLED=true
NIMBUS_SMS_USER_ID=hexabiz
NIMBUS_SMS_PASSWORD=K97%DSb*
NIMBUS_SMS_SENDER_ID=HEXACR
NIMBUS_SMS_ENTITY_ID=1701178799996228439
NIMBUS_SMS_TEMPLATE_ID=1777178824647145094
Restart the dev server after changing env vars.

Local testing without SMS (default):

OTP_SMS_ENABLED=false
OTP_DEMO_CODE=123456
OTP 123456 is returned in the API response and auto-filled in the UI.

Security notes
Never commit NIMBUS_SMS_PASSWORD to git — use .env.local only
OTP is stored in Supabase until verified, then cleared.
OTP expires after 10 minutes (matches SMS template).
demoOtp is only returned when OTP_SMS_ENABLED=false.
How to test
Demo mode: Go to /login, enter mobile, use OTP 123456.
Live SMS: Set OTP_SMS_ENABLED=true + Nimbus credentials, restart server, use your real mobile, check SMS, enter the code.
If SMS fails, check server logs for Nimbus OTP SMS failed — that includes the provider error response.
